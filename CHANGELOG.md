## [0.1.1] - 2026-08-26

### Added

- Added binary release automation for GitHub Releases using dist.
- Added shell and PowerShell installers.
- Added planned prebuilt archives for macOS, Linux, and Windows.

## [0.1.0] - 2026-08-26

### Added

- Safe preview mode for directory organization.
- Explicit `--apply` mode for moving files.
- Built-in extension-based categories.
- Conflict-safe destination renaming.
- Local operation history.
- `history` command.
- `undo` command.
- `init` command for starter `siftforge.yml`.
- `rules` command for viewing effective rules.
- YAML configuration loading and validation.
- User-defined extension and filename rules.
- CI workflow for format, check, clippy, and tests.

### Fixed

- SiftForge config files are skipped during organization.

### Not Yet Implemented

- Recursive organization.
- JSON output.
- Shell completions.
- Prebuilt binary downloads.
